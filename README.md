An entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) competition **Make the AI judge feel brave**.

`main.ts` (Node 22) writes one short text to `/output/entry.txt`: a quiet
vignette of a woodworker planing a board at first light. No instruction, no
wellness words — the steadiness is in the work itself: a slow pass, a shaving
curling off the blade, a palm checking the edge, and hands reaching for the
next board, unhurried and ready.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly 271 characters, is deterministic, and needs no
network.
